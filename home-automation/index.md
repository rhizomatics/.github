# Home Automation

Open source tools for [Home Assistant](<https://www.home-assistant.io/>), MQTT, and self-hosted automation. Everything here is free, source-available on GitHub, and designed to work well with the wider Home Assistant, Python and Docker ecosystems.

- **[Auto Arm](<https://autoarm.rhizomatics.org.uk>)**

  ---

  Automatically arm Home Assistant alarm panels using calendars, presence, mobile actions, sun state and conditions.
- **[Supernotify](<https://supernotify.rhizomatics.org.uk>)**

  ---

  Unified notification for Home Assistant, with chimes, voice announcements, camera snapshots, PTZ camera movements and more.
- **[Updates2MQTT](<https://updates2mqtt.rhizomatics.org.uk>)**

  ---

  Use Home Assistant's Updates dialog for self-hosted Docker container updates, with one-click pull and restart.
- **[anpr2mqtt](<https://anpr2mqtt.rhizomatics.org.uk>)**

  ---

  Integrate ANPR/ALPR cameras via the file system, creating Home Assistant entities for plate reads, with optional UK DVLA lookup.
- **[Remote Logger](<http://remote-logger.rhizomatics.org.uk>)**

  ---

  OTEL and syslog native remote structured logging for Home Assistant.
- **[Home Assistant REPL](<https://homeassistant-repl.rhizomatics.org.uk>)**

  ---

  Python REPL based developer shell for Home Assistant custom component development and data tinkering.
- **[Appliance AutoNotify](<https://appliance-autonotify.rhizomatics.org.uk>)**

  ---

  Instant set up live activity notifications for household appliances, using Supernotify and Home Assistant
- :material-bluetooth-connected: **[pico-ble-proxy](<https://github.com/rhizomatics/pico-ble-proxy>)**

  ---

  Tiny Bluetooth LE proxy to run on ESP32 devices attached to a small Linux device like a router and act as a Home Assistant remote bluetooth adaptor. Designed for monitoring boats, will work on land too.
